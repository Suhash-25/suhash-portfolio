## 🛠 Tech Stack

- **Framework**: React 18 + Vite 6 + TypeScript
- **Styling**: Tailwind CSS 3 with custom glassmorphism, glowing borders, and bespoke typography (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`)
- **Animation & Effects**: Framer Motion, HTML5 Canvas Particle Engine, Canvas Confetti
- **Icons**: Lucide React

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
```
